# UE5-RPG-Core

A reusable RPG framework layer for Unreal Engine 5, built on top of GAS (Gameplay Ability System).

## Module Structure

- **RPGFramework**: Base interfaces, attribute sets, ability system extensions
- **GameplayMechanics**: Combat, damage calculation, utility systems

## Integration Guide

### 1. Create a new UE5 C++ project

Use Unreal Engine to create a new C++ project (e.g., named `MyGame`).

### 2. Clone this repository into your project

```bash
cd MyGame/Source
git clone https://github.com/yourname/UE5-RPG-Core.git RPGCore
```

### 3. Register the module in `.uproject`

Open `MyGame.uproject` and add the `RPGCore` module:

```json
{
  "Modules": [
    {
      "Name": "MyGame",
      "Type": "Runtime",
      "LoadingPhase": "Default"
    },
    {
      "Name": "RPGCore",
      "Type": "Runtime",
      "LoadingPhase": "Default"
    }
  ]
}
```

### 4. Update Target files

In `Source/MyGame.Target.cs` and `Source/MyGameEditor.Target.cs`, add `"RPGCore"`:

```csharp
ExtraModuleNames.AddRange(new string[] { "MyGame", "RPGCore" });
```

### 5. Add dependency in your game module

In `Source/MyGame/MyGame.Build.cs`, add `"RPGCore"` to public dependencies:

```csharp
PublicDependencyModuleNames.AddRange(new string[] {
    "Core", "CoreUObject", "Engine", "InputCore",
    "GameplayAbilities", "RPGCore"
});
```

### 6. Enable required plugins

RPGCore depends on these plugins. Add them to `MyGame.uproject`:

```json
{
  "Plugins": [
    {
      "Name": "GameplayAbilities",
      "Enabled": true
    },
    {
      "Name": "MotionWarping",
      "Enabled": true
    },
    {
      "Name": "Niagara",
      "Enabled": true
    }
  ]
}
```

### 7. Compile

```bash
& "C:\Program Files\Epic Games\UE_5.4\Engine\Build\BatchFiles\Build.bat" `
  MyGameEditor Win64 Development `
  -Project="C:\Path\To\MyGame\MyGame.uproject" `
  -WaitMutex
```

### 8. Start using

Your project can now:
- Inherit from `RPGGameplayAbilityBase` for abilities
- Inherit from `RPGAttributeSetBase` for attribute sets
- Implement `ICharacterDataInterface` for characters
- Use `URPGAbilitySystemLibrary` utility functions
